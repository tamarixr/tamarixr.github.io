Thème 1 — Chapitre 2

Microorganismes, microbiote et transmission des maladies

Objectif : connaître le vocabulaire, reconnaître les différents types de microorganismes, expliquer le rôle du microbiote et distinguer les modes de transmission des maladies.
Fiche construite à partir de ta fiche de révision. Les exemples et notions ci-dessous reprennent son contenu.

01 Le vocabulaire à connaître

  • Microorganisme : être ou agent microscopique, invisible à l’œil nu.
  • Agent pathogène : microorganisme ou agent capable de provoquer une maladie.
  • Microorganisme utile : microorganisme qui apporte un bénéfice à son hôte.
  • Transmission directe : passage d’un agent pathogène directement d’un individu à un autre.
  • Maladie vectorielle : maladie transmise par l’intermédiaire d’un vecteur.
  • Hôte : être vivant qui héberge un microorganisme ou un agent pathogène.
  • Réservoir de pathogènes : milieu ou être vivant dans lequel des agents pathogènes peuvent être présents (ex. : eau contaminée, êtres vivants).
  • Épidémie : augmentation et propagation d’une maladie dans une population.
  • Prophylaxie : comportements individuels et collectifs qui permettent de limiter une épidémie.
  • Microbiote : ensemble des microorganismes vivant dans un milieu donné, par exemple dans le corps humain.
  • Symbiose : association durable entre deux êtres vivants, avec un bénéfice pour les organismes associés.
  • Dysbiose : déséquilibre du microbiote.

03 Le microbiote et la santé humaine

Le microbiote joue un rôle dans la santé humaine. Il peut être modifié par des facteurs environnementaux.

AntibiotiquesPeuvent perturber le microbiote et provoquer un déséquilibre appelé dysbiose.
Consommation de fibresFavorise le rééquilibrage du microbiote.
À retenir : antibiotique → perturbation possible du microbiote → dysbiose. Consommation de fibres → aide au rééquilibrage du microbiote.

04 Les modes de transmission

Transmission directe

L’agent pathogène passe directement d’un individu à un autre.

Exemples à savoir :
  • Grippe → virus responsable : influenza.
  • SIDA → virus responsable : VIH.

Transmission vectorielle

Un vecteur transmet l’agent pathogène d’un hôte à un autre.

Exemple : paludisme → vecteur : moustique anophèle.
